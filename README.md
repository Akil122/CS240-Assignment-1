CS240 Assignment 1: Converter and Pixel System

Description:

This projects has a lot of programs that are related to representing information as bits and numbers:
1. Converting ASCII to decimal.
2. A number-base convertor that supports binary, decimal, octal, and hexadecimal.
3. A program that reads an image and converts its pixels.
4. A program that consumes pixels and creates an image.
5. It also tests boundaries for for unsigned and two's-complement values.


Requirements:
1. Python 3
2. Pillow (PIL)

Instal pillow with:
pip3 install Pillow

Files:
1. Assignment 1: Main python Source Code.
2. smiley.png: Input image used for pixel conversion.
3. input.txt: pixel data used for rebuild an image.
4. output.txt: Pixel values generated from input image.
5. output.png — Image rebuild from the pixel data.
6. output 2.txt — Additional output generated during testing.


How to Run:
1. Open the project folder in VS Code.
2. Open Assingment 1.py.
3. Run the program using the Python Run button or the terminal.
4. Follow the prompts for the number-base converter.

The program can also be ran from the terminal with:
python3 "Assingment 1.py"


Example, For a Binary Input:
Enter a number: 1010
Enter the base (2, 8, 10, or 16): 2

Binary: 0b1010
Decimal: 10
Octal: 0o12
Hexadecimal: 0xa
